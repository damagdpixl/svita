# Svita v0.1.0

First public release.

## Українською

**Svita** («Світа») — офлайн-гардероб для Android: каталог речей, підбір образів,
щоденник носіння і пакувальні списки. **Без акаунтів, без хмари, без телеметрії.**

- **Каталог гардеробу** — речі з кількома фото, категоріями, тегами, сезонами,
  ціною та нотатками; масовий імпорт фото.
- **Багата кастомізація** — редаговані категорії та власні поля (текст / число /
  список / мультивибір / колір), менеджер тегів. Жодних «фіксованих таксономій».
- **Підбір образів (dress-me)** — за погодою і вашим комфортом (слайдер ±15 °C);
  повністю офлайн з вбудованими кліматичними нормами, за бажанням — погода з
  Open-Meteo (без ключа).
- **Паперова лялька-аватар** — приміряйте образи на шаруватий аватар або
  подивіться у вигляді розкладки.
- **Календар і щоденник носіння** — плануйте образи, записуйте, що носили;
  нагадування «не носилось 60 днів».
- **Статистика** — cost-per-wear (ціна за носіння), найчастіше/найрідше носії.
- **Пакувальні списки** — збирання в поїздку з підказками з запланованих образів.
- **Власність на дані** — повний експорт/імпорт (JSON + фото), CSV-експорт.
  Ніякого lock-in.
- Приватність за замовчуванням: працює в авіарежимі; єдиний необов'язковий
  мережевий виклик — прогноз погоди.
- Ліцензія: **GPL-3.0**.

## English

**Svita** is an offline-first wardrobe app for Android: catalog your clothes, get
outfit picks, track what you actually wear, and pack for trips.
**Zero accounts, zero cloud, zero telemetry.**

- **Wardrobe catalog** — multi-photo items with categories, tags, seasons, price
  and notes; bulk photo import.
- **Rich customization** — editable categories and custom fields (text / number /
  enum / multi-select / color), tag manager. No fixed taxonomies.
- **Dress-me engine** — outfit picks by weather + your comfort (±15 °C slider);
  fully offline with built-in climate norms, optional Open-Meteo forecasts
  (no API key).
- **Paper-doll avatar** — try outfits on a layered avatar or view them as a
  flat-lay collage.
- **Calendar & wear log** — plan outfits, log what you wore, «not worn in
  60 days» nudges.
- **Stats** — cost-per-wear, most/least worn.
- **Packing lists** — trip packing with suggestions from planned outfits.
- **Data ownership** — full export/import (JSON + photos), CSV export. No lock-in.
- Privacy by default: works in airplane mode; the only optional network call is
  the weather forecast.
- License: **GPL-3.0**.
